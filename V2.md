# v2 development

Development branch only; main and HACS submission are unchanged.

## Implemented

- Strict finite nonnegative readings; unknown status is neutral and has no controls.
- Byte/decimal/binary storage units converted to decimal GB; unknown units hide raw totals.
- Explicit used/total overrides; percentage overrides do not inherit unrelated Proxmox totals.
- Optional Beszel HA entity mappings, with no silent cross-source fallback or direct Beszel credentials.
- Stop/reboot confirmations (default on), disabled unavailable controls, in-flight request guard and service errors.
- Shadow DOM isolates card styling; node names inserted as text.

```yaml
type: custom:proxmox-guest-card
entity: binary_sensor.your_guest_status
metrics_source: beszel
beszel:
  cpu_entity: sensor.your_beszel_cpu
  ram_entity: sensor.your_beszel_ram_percentage
  ram_used_entity: sensor.your_beszel_memory_used
  ram_total_entity: sensor.your_beszel_memory_total
```

Use actual HA entity IDs. Percentages require `%`; raw sizes require a recognized B/kB/KB/MB/GB/TB/KiB/MiB/GiB/TiB unit. RAM percentage can be derived from valid used/total when no percentage is available. Disk supports disk_entity/disk_used_entity/disk_total_entity inside beszel too. Default metrics_source is proxmox; top-level ram_used_entity/ram_total_entity/disk_used_entity/disk_total_entity are optional overrides.
